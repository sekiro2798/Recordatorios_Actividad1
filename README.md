# Recordatorios — Actividad 1

## Descripción del proyecto

Este proyecto corresponde a la Actividad 1 de la asignatura **Programación Mobile**. Consiste en el desarrollo de una aplicación Android de recordatorios utilizando Kotlin y Android Studio.

El objetivo de la actividad es aplicar los conocimientos iniciales de programación móvil y familiarizarse con la estructura de un proyecto Android.

## Tecnologías utilizadas

- **Kotlin:** lenguaje de programación.
- **Android Studio:** entorno de desarrollo.
- **Android SDK:** herramientas para desarrollar y ejecutar aplicaciones Android.
- **Gradle:** sistema de compilación y gestión de dependencias.

## Estructura del proyecto

- `app/`: módulo principal de la aplicación.
- `app/src/main/java/`: código fuente en Kotlin.
- `app/src/main/AndroidManifest.xml`: configuración de la aplicación.
- `gradle/`: archivos necesarios para la compilación.
- `build.gradle.kts`: configuración de Gradle.
- `settings.gradle.kts`: configuración de los módulos del proyecto.

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir Android Studio.
3. Seleccionar **File → Open**.
4. Abrir la carpeta principal del proyecto.
5. Esperar a que finalice la sincronización de Gradle.
6. Seleccionar un emulador o dispositivo Android compatible.
7. Presionar **Run** para compilar y ejecutar la aplicación.

## Objetivo de aprendizaje

Comprender la organización básica de una aplicación Android, trabajar con Kotlin y utilizar las herramientas de Android Studio para desarrollar y ejecutar un proyecto móvil.
